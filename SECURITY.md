# Security Policy 🔒

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Yes    |
| < 1.0   | ❌ No     |

## 🛡️ Reporting a Vulnerability

We take security seriously at **LiveStockSafe**. If you discover a security vulnerability, please follow responsible disclosure:

1. **Do NOT** open a public GitHub Issue for security flaws
2. Email us privately at: **beshu4959gowdaman@gmail.com**
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will acknowledge receipt within **48 hours** and aim to release a patch within **7 days** for critical issues.

## 🔐 Security Best Practices (for contributors)

- Never commit `.env` files or secrets
- Use environment variables for all credentials
- Validate and sanitize all user inputs
- Use HTTPS for all API communications
- Keep dependencies updated (`npm audit`)

Thank you for helping keep LiveStockSafe safe! 🙏
